# Project instructions

For experiment management, training, evaluation, result reporting, algorithm changes, or project documentation, use the `managing-research-project` skill in `.agents/skills/managing-research-project/SKILL.md`.

For every training configuration, launch, resume, monitor, interruption, or failure diagnosis, also use `.agents/skills/running-research-training/SKILL.md`. Parameter correctness comes first. Keep tests focused. If a nonessential or legacy constraint blocks training, report it immediately and let the user decide whether to keep, relax, or remove it.

The living documents under `docs/` are authoritative. Files under `docs/archive/` are historical leads and are not direct evidence.
